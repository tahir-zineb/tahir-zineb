# Profile README generator

Everything shown in the profile README is generated by these scripts.

| File | Role |
|---|---|
| `profile.json` | Texts, links, key figures, "What I do" rows |
| `tech.json` | Technologies, their category and logo source |
| `fetch_glyphs.py` | Downloads each logo once and writes `glyphs.json` (committed, so builds work offline) |
| `build_assets.py` | Writes `assets/icons/{dark,light}/`, `assets/ui/{dark,light}/` and `README.md` |
| `components.py` | Header, buttons, section titles, key figures, rows |
| `fonts/` | Inter (SIL Open Font License, see `OFL.txt`), used to measure text |

```bash
pip install fonttools svgpathtools
python tools/fetch_glyphs.py   # only after changing tech.json
python tools/build_assets.py
```

Each visual exists in a dark and a light variant; the README uses `<picture>` so GitHub picks the one matching
the viewer's appearance setting.

Logo sources: [Simple Icons](https://simpleicons.org) 16.31.0 and 9.21.0 (CC0),
[AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) (2026-07-31 package). All trademarks belong to their owners.
